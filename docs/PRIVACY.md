# AppLayout プライバシーポリシー

AppLayoutは、画面に表示する候補の取得と配置の復元のため、Windowsからウィンドウのタイトル、アプリの識別情報、位置、サイズを読み取ります。タイトルやパスには、開いている文書名などが含まれる場合があります。

アプリは、登録した配置、識別条件、表示言語などの設定を端末内の `layout.json` に保存します。トレイへの縮小演出で使用するウィンドウ画像は一時的にメモリで扱います。アカウント登録、広告、アクセス解析はなく、アプリがこれらの情報を開発者や第三者に送信することはありません。

保存済みの配置はアプリの「すべての配置を解除する」で削除できます。設定全体を削除する場合は、アプリを終了して [READMEの保存先](../README.md) にある `layout.json` を削除してください。

ご質問は [AppLayoutのサポートページ](https://github.com/nekomimiyks/AppLayout/issues) へお寄せください。

## AppLayout Privacy Policy

AppLayout reads window titles, application identifiers, positions, and sizes from Windows to list windows and restore their layouts. Titles and file paths may contain information such as the names of open documents.

AppLayout saves registered layouts, matching rules, language preferences, and other settings locally in `layout.json`. Images used for the animation to the system tray are held temporarily in memory. AppLayout requires no account, includes no ads or analytics, and does not send this information to the developer or third parties.

You can remove saved layouts using “Clear all layouts” in the app. To remove all settings, exit AppLayout and delete `layout.json` from the location listed in the [README](../README.md).

For questions, see the [AppLayout support page](https://github.com/nekomimiyks/AppLayout/issues).
