# AppLayout 仕様書（配置台帳版・2026-11-14）

Windowsで起動したアプリのウィンドウ配置（位置・サイズ）を記憶し、約2秒ごとに記憶した位置へ戻し続ける常駐アプリ。

## 技術条件（必須）

- C# 5 まで（.NET Framework 4.x 標準の `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` でビルドする）。
  - 使えない構文: `$"..."` 文字列補間、`?.`、`nameof`、式形式メンバー `=>`（ラムダは可）、自動プロパティ初期化子、`out var`、タプル、`is` パターン など。
- WinForms。外部ライブラリ・NuGet 不可。参照は System, System.Core, System.Drawing, System.Windows.Forms, System.Runtime.Serialization のみ。
- ビルドは `build.ps1`（PowerShell）。画面は `src/ui`、共通処理は `src/core`。ソースは UTF-8。
- 他のWindows PC（Windows 10/11、日本語/英語、DPI 100〜200%、複数モニタ）でもそのまま動くこと。
  - ユーザー名やフォルダを決め打ちしない。
  - 高DPIでも文字や部品が潰れない・はみ出さない（サイズ指定は `Ui.S()` / `Ui.Sz()` でDPI倍率を掛ける。プロセスは Per-Monitor V2 で動作）。
  - 設定ファイルは exe と同じフォルダの `layout.json`。書き込めなければ `%APPDATA%\AppLayout\layout.json`（`ConfigStore.DefaultPath()` 実装済み）。

## 画面に出す言葉（そのまま使う）

- 状態: 配置中 / 位置を戻しました / 最小化中 / 未起動 / 一時停止中 / 該当が複数 / 未保存 （「キープ」という言葉は使わない）
- スイッチ（短いラベル＋マウスオーバーで詳しい説明のツールチップ）
  - 「配置を有効」: オンの間、保存したウィンドウを約2秒ごとに保存位置へ戻します。オフにするとウィンドウを自由に動かせます。
  - 「ログイン時に自動起動」: Windowsにサインインしたとき、画面を出さずにタスクトレイに常駐した状態で起動します。
  - 「アプリ自動起動」: ログイン時の自動起動のとき、保存済みのアプリが起動していなければ起動します。
  - 「アプリ終了時自動縮小」: ×ボタンで閉じたとき、終了せずにタスクトレイに入ります。オフのときは×で終了します。
- 行の対象をスイッチで切り替え、その瞬間に設定ファイルへ保存する。ONは現在位置・サイズを登録、OFFはその行の登録だけを解除。他の行の位置や条件は変更しない。保存失敗時はメモリ上の変更も戻す。
- 「今の位置で配置」は廃止。上部の主な操作は次の2つ。
  - 「すべての配置を解除する」: 確認画面で同意したとき全登録を解除する。ウィンドウ自体は閉じない。
  - 「配置を実行」: 登録済みの配置を実行する。未起動・最小化中・複数該当はそのまま。
- 「配置を有効」は常時表示。その他3つの設定は、背景・枠付きの「設定を開く／設定を閉じる」ボタンで開閉する。展開中は背景と枠の色も変える。
- 配色はWindowsの「アプリのモード」に合わせる。起動中の変更にも追従し、編集中の入力、ON/OFF、フォーカス、スクロール位置を維持する。
- Windowsの設定変更通知、テーマ変更通知、UserPreferenceChangedを監視し、画面を開き直す必要なく再配色する。設定は読み取りのみでWindows側の配色は変更しない。
- 文字は96DPIのWindows標準フォント（NONCLIENTMETRICSの本文／メニューフォント）を基準にする。OSから返る文字拡大を再乗算しない。古いWinFormsのシステムDPIへの依存を避け、表示先DPIを1回掛けたPixelフォントで描画する。
- DPIと文字拡大は別に反映し、起動中の文字設定変更・モニタ移動時にも更新する。通常時は本文9pt相当、見出しは本文の1.3倍、行高44論理pxを目安とし、大文字設定では実測で拡張する。名前の常時太字は使わない。
- 一覧・編集領域の縦横スクロールバーは、標準SCROLLBARを表示せず専用Controlで描画する。背景・つまみ・矢印・ホバー／押下色を配色に合わせ、ドラッグ・ホイール・矢印・Page/Home/Endに対応する。
- スクロールバーの描画はOnPaintとダブルバッファに統一し、状態が変わるときだけ再描画する。画面DCへの重ね描き・ホバー再描画タイマー・標準テーマの無効化は行わない。入力リピート用タイマーは矢印／ページを押している間だけ動作する。
- 一覧はGridScrollHostで可変行高と表示範囲を同期し、編集領域と外側レイアウトはThemedScrollPanelで内容の表示位置を管理する。詳細識別情報は全文の高さを確保し、領域全体をスクロールする。
- 起動時は物理カーソルのあるモニタに表示し、初回のDPI確定後に列の内容幅・行数・操作領域・実ウィンドウ枠から必要サイズを計算する。名前・見分け方の幅には上限を設け、作業領域と余白を優先して縮小する。起動後の定期更新やトレイ復帰ではサイズを再計算しない。
- 大文字設定や小さい画面では操作バーを折り返し、編集画面のラベルは折り返す。必要に応じ表の横スクロール・編集内容の縦スクロールを利用でき、確定ボタンは常時見える。DPI変更で窓が画面より大きくなる場合は作業領域に収める。

## 表示言語

- `language` 設定の未指定・不明値は `auto`。Windowsのユーザー優先表示言語を判定し、地域付きコードを日本語・英語・簡体字・繁体字・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語へ解決する。未対応時は英語。
- 「設定を開く」の言語選択で上書きし、配置と同じ設定ファイルに保存する。メイン画面、開いている編集画面、トレイメニューへ即時反映する。利用者のアプリ名・タイトル条件・未確定の入力・登録座標を変更しない。
- 翻訳JSONはビルド時にexeへ埋め込む。外部ファイルやネットワーク接続は不要。

## 一覧

- 行 = 「保存済みのアプリ」＋「いま起動していて、まだ保存していないウィンドウ」。
- モニタ番号ごとにグループ化。番号はWindowsの 設定>ディスプレイ と同じ。登録済みは保存先、未登録は現在地で分類し、未接続・不明にも専用グループを設ける。
- 列: 対象スイッチ / 名前・プロセス（2段） / 位置・サイズ（2段） / 見分け方 / 最大化 / 登録状態・動作状態（2段） / 編集。
- 保存済みの行は保存内容を表示。未保存の行は今の位置と、見分け方・最大化は既定値（「アプリで判定」「いいえ」）を表示。
- 行や対象スイッチのクリックでON/OFFを切り替える（Ctrl不要、Spaceでも操作可）。登録済みの行はON、未登録はOFF。切り替え後に確定ボタンを押す必要はない。
- ONは緑系のスイッチと行全体の灰緑色、OFFはグレーのスイッチと通常背景。色に加えてON/OFF文字とつまみ位置で区別する。設定・編集画面の最大化も同じスイッチ部品を使う。
- 登録／解除で行のキーが変わっても同一ウィンドウの表示行・到着順・フォーカスを引き継ぐ。表を毎回作り直さず、ダブルバッファと差分更新でちらつきを抑える。
- 編集ボタン: 名前・見分け方・位置・サイズ・最大化を編集するダイアログ（`EntryEditDialog`、実装済み）を開く。未保存の行で押した場合は、OKで新規保存。
- 編集画面: 名前→配置（X/Yと幅/高さを2列）→見分け方の順。ラベルは入力欄の上に置き、タイトル条件は条件が必要なモードだけ表示する。照合件数と配置先モニタを表示し、詳細識別情報は開閉式。「登録を確定」で保存、「キャンセル」で元の内容を維持する。正規表現の照合には時間上限を設ける。

## トレイ（システムトレイ）

- 最小化したとき、タスクバーから消えてトレイアイコンだけになる。
- ×で閉じたとき、「アプリ終了時自動縮小」がオンならトレイへ、オフなら終了。
- ×でトレイへ入る際は画面の写しを約220msで通知領域へ縮小・移動させ、薄くして消す。写しはフォーカスを奪わず、タスクバーにも追加しない。Windowsのアニメーション無効設定・リモートセッションでは演出を省く。実際に終了するときは演出しない。
- ログイン時の自動起動（引数 `/startup`）では画面を出さずトレイに常駐。
- トレイアイコン右クリックメニュー: 「アプリを開く」「配置を実行」、区切り線、「アプリを終了する」。ダブルクリックで開く。
- トレイメニューはWindowsの「Windowsのモード」（タスクバー側）に追従する。角丸・余白・ホバー背景を備え、アプリのモードとWindowsのモードを別に設定した場合もそれぞれに従う。開くたびと表示中の変更で配色を更新し、表示先モニタのDPIにも合わせる。
- メニューを開く時点の物理カーソル座標から表示先モニタを固定する。初期Boundsや前回表示したモニタを基準にせず、同じモニタのDPIと作業領域で位置・寸法を決める。負のモニタ座標・画面端・タスクバー上でもそのモニタ内へ収める。
- 二重起動したら、既に動いている方の画面を前に出す。exe名・UI案・配置フォルダによらず同じWindowsセッションでは1プロセスのみ。
- 採用アイコンは `src/assets/applayout.png`。ビルド時に16～256pxの9サイズを含む `src/app.ico` を生成し、実行ファイルとトレイで共用する。

## 自動復元（実装済み: Keeper）

- 約2秒ごとに保存済みエントリに一致するウィンドウを探し、保存位置と違えば戻す。最小化中・マウス左ボタン押下中（ドラッグ中）は触らない。保存位置のモニタが無いときも触らない。
- 一致条件: プロセス名・クラス名（実行ごとに変わる部分は除く）・AppUserModelID・タイトル条件。一致が複数なら戻さない（状態「該当が複数」）。
